## 📖 About The Project

**Wanderlust** is a full-stack travel platform where users can securely create accounts, log in using Email/Password or Google Authentication, and explore a modern web experience.

This project was built to strengthen my full-stack development skills while learning modern technologies like **React, Next.js, Node.js, Express.js, and MongoDB**.

Beyond coding, this project taught me how to break large problems into smaller tasks, debug efficiently, and build complete real-world applications from scratch.

# ⚙️ Installation

Clone the repositories

```bash
git clone https://github.com/pervezmia/wanderlust.git

git clone https://github.com/pervezmia/wanderlust-server.git
```

### Client

```bash
cd wanderlust

npm install

npm run dev
```

### Server

```bash
cd wanderlust-server

npm install

npm start
```

---

# 🔑 Environment Variables

Create a `.env` file inside both client and server.

### Client

```env
NEXT_PUBLIC_API_URL=

NEXT_PUBLIC_FIREBASE_API_KEY=

NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=

NEXT_PUBLIC_FIREBASE_PROJECT_ID=

NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=

NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=

NEXT_PUBLIC_FIREBASE_APP_ID=
```

### Server

```env
PORT=

MONGODB_URI=

JWT_SECRET=
```
